# Opt-in list of files/globs (relative to `src-app/ui/src`, forward slashes,
# `*` = any chars except `/`, `**` = any chars incl. `/`, a trailing `/`
# means "everything under this directory") that have been MIGRATED to the
# actions model — i.e. their interactive user-mutation affordances are
# expected to go through a registered `defineAction` (via `<ActionButton
# action="...">` or `useAction`), not an inline `onClick` that calls a store
# action directly.
#
# `scripts/action-coverage.mjs` only checks files listed here. An empty
# allowlist (the default) passes trivially — enforcement grows file-by-file
# as the codebase migrates to the actions model (DEC-6: a repo-wide inline-
# onClick hard-fail is not statically decidable; ITEM-15 descoped it).
#
# One glob per line. Lines starting with `#` and blank lines are ignored.
#
# Example (once a directory is migrated):
# modules/command-palette/**
