# action-coverage allowlist (ai-actions ITEM-12 / DEC-6)
#
# Files/globs (relative to `src-app/ui/src`, forward slashes, `*` = any chars
# except `/`, `**` = any chars incl. `/`, a trailing `/` means "everything under
# this directory") that are ALLOWED to call a store action from an inline
# `<Button onClick>`, instead of going through a registered `defineAction`.
#
# `scripts/action-coverage.mjs` checks EVERY source file under `src` and skips
# only the files listed here. An entry that matches no file fails the check, so
# delete an entry when its file is moved or removed.
#
# One glob per line, each with a reason in a comment above it. Lines starting
# with `#` and blank lines are ignored. The list is empty on purpose: an entry
# is an exception to the rule that every user action is declared once, and needs
# the user's review.
