# Outbound hosts the shipped application may reach.
#
# Hosts are matched exactly. Loopback (127.0.0.1, localhost, ::1, 0.0.0.0) and
# the RFC 2606 example names (*.example, example.com/net/org, *.invalid, *.test)
# are always allowed by the guard and are not listed here. Anything else found
# as an http(s):// literal in shipped non-test source fails
# scripts/check-network-allowlist.sh. An entry that matches no literal in the scan
# roots also fails the guard, unless its line carries the tag `# scheme-less`
# (the host is used by a tool and never spelled with a scheme in the source).
#
# ghcr.io is not spelled with a scheme in the source (the registry is a string
# constant passed to `oras`), so it is listed here as the approved host rather
# than extracted. Two uses: the method environment downloads (pinned layers and
# bases, by digest) and the method list check (`method_list::fetch`: resolve
# `ghcr.io/tinnlab/txresbench-method-list:v1`, pull a new list by digest).
ghcr.io # scheme-less
# GHCR's blob host: GHCR answers every blob GET with a redirect (307) here
# (verified 2026-11-16), so the env downloads and the method list pull both
# reach it through `oras`. Not spelled in the source; listed so a firewall or
# proxy note names both hosts the app needs.
pkg-containers.githubusercontent.com # scheme-less
# OIDC issuer asserted during cosign keyless verification of env images.
token.actions.githubusercontent.com
# Any https:// github.com literal in the source is the user-opened
# documentation link (Settings > Help); the app never dials it.
# (pretrained-catalogue DEC-15: the model-asset URL template
# `https://github.com/tinnlab/txresbench-models/releases/download/...` is
# the asset GET; covered by this entry.)
github.com
# Any https:// doi.org literal in the source is the method card's
# user-opened paper link; the app never dials it (the same class as the
# github.com documentation-link entry above — a browser-opened href).
doi.org
# The pretrained-catalogue boot/on-demand catalogue refresh
# (`https://tinnlab.github.io/txresbench-app/pretrained-catalogue.json` —
# the GitHub Pages site hosting the served copy, PROV-landing-site-3).
tinnlab.github.io
# The GitHub release-asset redirect target a model download follows
# (PRETRAINED asset.url → redirect). Listed so the runtime-host rule can
# verify the real host, not just the literal one.
objects.githubusercontent.com # scheme-less
# Apple Sign-In verification (auth module).
appleid.apple.com
# Tauri's IPC endpoint on Windows, named in the window's Content Security Policy
# (tauri.conf.json app.security.csp, `connect-src ... http://ipc.localhost`).
# WebView2 serves the app's own schemes as http://<name>.localhost and hands
# these requests to the app's IPC handler; nothing leaves the machine (macOS
# and Linux use the `ipc:` scheme for the same channel).
ipc.localhost
# The Tauri config `$schema` document (a JSON-schema identifier, never fetched).
schema.tauri.app
